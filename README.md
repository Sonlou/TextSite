# TextSite

TextSite is an AI-powered website generator that turns plain text prompts into complete websites.

## What it does
- Describe the website you want in natural language
- Generate a modern landing page or web app design
- Preview it instantly in the browser
- Download the generated HTML file

## Run locally

```bash
npm install
npm run dev
```

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- DeepSeek API
