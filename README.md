# 🚀 TextSite

TextSite is an AI-powered website generator that turns plain-text prompts into polished, responsive websites.

## ✨ What it does
- Turn natural-language ideas into complete website layouts
- Generate modern, production-style UI designs
- Preview the result instantly in the browser
- Download the generated HTML file for reuse

## 🧠 Example prompts
- "Create a modern fintech landing page"
- "Build a portfolio website for a designer"
- "Design a restaurant homepage with an online menu"
- "Create a dashboard for an e-commerce admin panel"

## 🛠️ Run locally

```bash
npm install
npm run dev
```

## 🧩 Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- DeepSeek API

## 📌 Purpose
TextSite helps users go from concept to working website quickly by describing what they want in plain English.
